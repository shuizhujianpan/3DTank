# 钢铁余晖 · 3D 坦克大战

本地单人 3D 坦克竞技场。无需账号、后端或网络资源。

## 运行

在项目目录运行 `python3 -m http.server 8000`，打开 `http://localhost:8000`。需支持 WebGL2 的现代浏览器。不要直接用 `file://` 打开，因为浏览器会拦截 JavaScript 模块。

## 操作

- `W A S D`：移动坦克
- 鼠标：转动炮塔瞄准
- 鼠标左键或空格：开火
- 击毁全部 5 辆敌方坦克获胜；装甲降到 0 则失败。结束后可重新开始。

3D 引擎为仓库内的 Three.js 0.180.0 文件，模型、场景、特效均由代码生成。Three.js 版权与许可见 `vendor/LICENSE`。
